# SUPERDETERMINISM

**80s ARCADE × DUB × DECONSTRUCTION**

飛ぶ。走る。落ちる。壊れる。  
その先でも、ゲームは続く。

![SUPERDETERMINISM ゲーム画面](assets/gameplay.jpg)

## この作品について

操作している手応えはある。それでも、世界の流れまでは変えられない。

夢で見たゲームを出発点に、80年代のアーケードゲームの文法を解体し、一本につなげた短編ブラウザゲームです。
不可避の出来事がゲームオーバーではなく、別の世界への入口になります。
タイトルの「スーパーデターミニズム」は作品の着想であり、物理学の理論をシミュレーションするものではありません。

## 六つの世界

| 世界 | ゲーム | 操作 |
| --- | --- | --- |
| VOID PILOT | 横スクロールシューティング | 上下左右で移動、Z / SPACEでショット |
| THE LONG WAY HOME | 横スクロールアクション | 左右で移動、SPACE / Z / 上でジャンプ |
| NO MORE SKY | 落下物に埋まる部屋 | 左右で移動、SPACE / 上でジャンプ、Zで迎撃 |
| DEAD CHANNEL DRIVE | レース | 上下左右で運転 |
| BREAK THE FRAME | ブロック崩し | 左右で移動、Z / SPACEでボールを押し戻す |
| EXIT NOT FOUND | 迷路 | 上下左右で移動、ドットを集める |

WASDでも移動できます。スマートフォンは画面下の方向キーとSHOT・JUMPボタンに対応します。
ボタンは長押しできます。P / PAUSEで一時停止、SOUNDボタンで音を切り替えられます。

## 演出

- ガネーシャへの変身、画面を覆う巨大化、100体への分裂
- タイル落下、横方向の断裂、中心への巻き込み、溶解、ブラインド剥離、ドット消失
- 六つの崩壊演出を、一周の間で重複しない順序にシャッフル
- ゲーム内に現れる架空のBIOS・エラー画面、別の世界のキャラクターの混入
- Web Audioによるビープ音、低音、DUBサイレンとディレイ

## 実行方法

`index.html`をブラウザで開き、PRESS STARTを押してください。
HTML・CSS・JavaScriptを一つのファイルに収録しています。ビルド、外部ライブラリ、APIキーは不要です。
音は開始操作後に再生されます。

静的Webサーバー、GitHub Pages、Cloudflare Pagesなどでも配信できます。
現在の公開版は上記のChatGPT SitesのURLです。このリポジトリへの変更はSitesへ自動反映されません。
